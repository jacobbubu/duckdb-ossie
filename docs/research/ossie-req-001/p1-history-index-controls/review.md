# 历史区间索引原生切片

有限历史的纯原生索引已实施并通过独立枚举与边界验证，见
[绑定证据](verification.json)。历史 profile 尚未注册启用；双源捕获、映射绑定、
SQL 查询/解释/发现与生命周期还需实现，因此不能称历史执行接口已完成。
承载与政策沿用[固定设计](../p1-history-carrier/design.md)。

算法先验证完整输入的全局 record_id、原始 User/target 与有限 start<end，按
User/target 合并连续覆盖，随后检查异目标重叠。索引保持原始来源行数，但不是
原始 collection 的替代品。查找利用排序段的二分定位，不创建观察×历史 bag；
index 自身不接收观察过滤器，不能因缺观察忽略冲突。raw identity 使用明确 UTF-8
字节比较，保留大小写和 NUL。所有遍历/排序/查找阶段接受取消检查。

20,474 检查包括 600 种双区间、User/目标组合，独立成对冲突及逐记录日期枚举；
嵌套隐藏冲突、源顺序轮换、同目标重复/相接、缺口、非法 ID/端点、有限极值。
10,000 同区间来源合成一个段，10,000 分离区间保留 10,000 段；后者的特定查找
最多 32 次比较检查，含段内命中、末点不含和查找取消。该样本不承诺任意运行
时间或峰值内存。验证/排序/合并/完成前取消均不返回部分 index，后续重建通过。
这里的控制是内部回调取消，不是 SQL 连接中断或发布恢复，后两者仍需实际验证。

release C++17 构建、clang-format11、架构与 Make 入口干运行通过。新 native 目标
加入三种 Make 测试入口及 Windows 默认构建。首轮新目标尚未经 CMake 重新生成，
返回 no rule；保留日志后复用现缓存重新生成并构建通过，没有重启仍运行的任务。
19 个源、日志及测试二进制原件由私有清单绑定。未重建共享产物并复验旧接口，
未宣称此切片通过 Linux/tidy 或远端 CI；最终新接口产物回归仍必需。

下一必要行动是历史 typed 双源定义/捕获与不可变父快照、原子发布，随后同一
请求的完整 link/compile/program、MCP 和无模型；完整五项 P1 保持未完成。
本切片仅本地提交，无真实模型、推送、合并或发布。
