# 历史 Agent 无模型循环与封存重放

七场景把真实 stock stdio MCP 接入模拟 Responses：全部观察、日期范围、产品 Y、
缺口、有限最小日期、空来源、只解释。[选择性报告](verification.json)与
[receipt](receipt.json)绑定 macOS ARM64 产物
`e04ff401f37318a92d381f5454ff47c6683d8c52288db8d7d3348eb5b2cf9e71`。
每执行场景最多三轮/两调用，只解释两轮/一次 compile，实际合计 20 次模拟响应、
13 次工具调用；只解释没有 query，也不返回计算后的链接或计数。

最终回答必须与对应实际工具的完整结果完全一致，同时检查请求范围、精确关系、
来源行数、固定定义文件 hash 与六项追踪值。独立逐记录 oracle 在旁路验收完整
成员，未放进模型可见的系统提示/问题/发现资源。两个结构合法的工具/答案共同
伪造仍会被独立 oracle 拒绝：错误目标和删掉一个成员并同步改计数。工具与答案
互相一致、JSON 结构正确都不是关系正确的充分证据。

29 项负控制通过，包括重新封存的错 schema/mode/runtime/产物身份/来源 hash、
缺场景/上下文/RPC、错问题/设置/证据 ID/工具参数/投影、尾随记录；还包括模型
响应不完整、未知外层参数、object 参数、内外层重复解码字段、错范围/关系和只
解释场景试图执行。后七种调用者门禁在实际 tools/call RPC 前拒绝，失败/部分
原件封存后不能通过完整 replay。原始未改，重封控制明确标记为合成伪造。

重放严格顺序消费全部事件，重新从公共 Responses 投影构造响应，核对 continuation/
call/RPC/evidence ID、保存的上下文/设置/最终审查和计数。验收在阻断 fetch 与
Node 子进程启动的环境中通过，两类观察计数为零；source seal 重放前后不变。
支持调用者提供产物 SHA 做身份绑定，归档里的安装路径只当元数据，不读取它
或执行归档代码。完整验收证明的是本地记录与合成来源的对应，不是远端响应
真实性、模型自主规划、真实业务结论或真实来源完整性。

原始会话与反例保持私有、由清单绑定，先前成功阶段和增加 runtime 门禁前的
源快照另保存。公共报告只包含选择性结论、场景计数、hash 和限制。Cpp 未改，
沿用[同 SHA 原生、SQL 和旧全接口回归](../p1-finite-window-controls/receipt.json)。
