这是本地 Docker ARM64 验收，不能声称远端 Ubuntu AMD64/macOS CI 已运行。此前 [macOS 功能及 Linux tidy](../p1-tidy-controls/review.md) 的证据保持原版本，新 Linux 功能证据补齐其当时未运行项。两个平台二进制不同 SHA 属于不同构建产物，不能要求二进制字节相同。

完整 P1 尚缺每日三值状态与历史关系口径确认及实现、对应对象/解释/发现/MCP和最后统一回归与交付审计。已有能力验收完成不等于整个 goal 完成。没有推送、合并或发布。

公开 SQL 日志仅去掉末尾空白以通过仓库空白检查；完整原件不变，receipt 分别绑定原始与公开 SHA。其他公开日志保持原字节。
