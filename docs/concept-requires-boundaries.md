# 概念 requires：类型与拒绝边界

本页说明 `concept-scalar-requires-v1` 的类型范围与拒绝边界，不增加类型、语法或 profile。

支持来源捕获的整数为 TINYINT、SMALLINT、INTEGER、BIGINT。HUGEINT、无符号整数和其他不支持来源类型仍拒绝；内部 IsIntegral 的范围不扩大来源捕获合同。现有约束只接受同 owner/同直接映射属性的 `IS NULL OR >= constant` 或 `IS NOT NULL AND >= constant`，guard 顺序可交换。

<a id="date-storage-boundary"></a>

## DATE 解析与存储边界

固定 DuckDB 1.5.6 可通过日期加整数构造物理日序 -2147483648，文本为
`5877642-06-23 (BC)`，其原始值比较结果小于负无穷哨兵；该文本作为 DATE 字面量绑定会拒绝。
可解析下界为 `5877642-06-25 (BC)`（日序 -2147483646），可绑定和重载。
这些是两个不同边界，不能互相替代；记录的是既有引擎行为，没有新增数学无穷或有限日期政策。

## 边界范围

- 四种整数的最小值、零、最大值、上下溢出；BIGINT 覆盖超过 JS 安全整数范围的精确值。拒绝小数、科学计数、字符串、NULL 及不支持的显式转换阈值。
- DATE 覆盖 BC、普通年份、闰日、宽年份、固定版本解析极值、正负无穷及跨度；拒绝非法日期、解析范围外日期、未类型化字符串和 TRY_CAST。沿用 DuckDB 1.5.6 语义，不新增有限日期或时区政策。
- 不支持的物理来源类型、requires 标量目标、计算映射及错误 owner/属性/运算符/函数/聚合/子查询/窗口。
- 8/9 项、单式 16 KiB 边界、总 128 KiB 边界和 AST 节点/深度边界。AST 限制按现有规则错误分类，不改成资源错误；条数和字节限制按资源错误分类。达到通用 AST 上限也不代表违反有限语法的表达式应该被接受。
- capability 的类型、空、重复、未知选择，以及其余四个 profile 对该选择的显式拒绝。不把"schema 可解析"当作这些 profile 支持新能力。

数据违约在空人口上按全称约束成立；坏声明在空人口上仍须预检拒绝，二者不能混用。

单源与双源维度模型共用同一语义；双源保留重复 FK、同名影子列和未引用维度。错误使用现有 error-v1 的 code、stage 及适用约束对象/索引。

本能力不覆盖新 profile、一般 Ontology 推理、完整 DATE/时间语法或任何时区政策。
