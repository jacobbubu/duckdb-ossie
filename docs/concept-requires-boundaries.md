# 概念 requires：类型与拒绝边界合同

本合同沿用 OSSIE-REQ-001，在既有 `concept-scalar-requires-v1` 范围补足边界验证，不增加类型、语法或 profile。基础 requires 与本合同的类型/拒绝边界已在固定 Mac ARM64 / DuckDB 1.5.6 完成限定原生验收；结果见下文。结论仍限定于对应冻结版本、产物和执行收据，案例生成或离线通过不能代替原生执行。

支持来源捕获的整数为 TINYINT、SMALLINT、INTEGER、BIGINT。HUGEINT、无符号整数和其他不支持来源类型仍拒绝；内部 IsIntegral 的范围不扩大来源捕获合同。现有约束只接受同 owner/同直接映射属性的 `IS NULL OR >= constant` 或 `IS NOT NULL AND >= constant`，guard 顺序可交换。

## DATE 解析与存储边界

固定 DuckDB 1.5.6 可通过日期加整数构造物理日序 -2147483648，文本为
`5877642-06-23 (BC)`，其原始值比较结果小于负无穷哨兵；该文本作为 DATE 字面量绑定会拒绝。
可解析下界为 `5877642-06-25 (BC)`（日序 -2147483646），已验证可绑定和重载。
这些是两个不同边界，不能互相替代；结果记录既有引擎行为，没有新增数学无穷或有限日期政策。

## 固定验证范围

独立确定性合同覆盖204案例，在非空与空人口上形成408组验证：

- 四种整数的最小值、零、最大值、上下溢出；BIGINT 另覆盖超过 JS 安全整数范围的精确值。拒绝小数、科学计数、字符串、NULL及不支持的显式转换阈值。
- DATE 覆盖 BC、普通年份、闰日、宽年份、固定版本解析极值、正负无穷及跨度；拒绝非法日期、解析范围外日期、未类型化字符串和 TRY_CAST。沿用 DuckDB 1.5.6 语义，不新增有限日期或时区政策。
- 不支持的物理来源类型、requires 标量目标、计算映射及错误 owner/属性/运算符/函数/聚合/子查询/窗口。
- 8/9项、单式16KiB边界、总128KiB边界和AST节点/深度边界。AST限制按现有规则错误分类，不改成资源错误；条数和字节限制按资源错误分类。达到通用AST上限也不代表违反有限语法的表达式应该被接受。
- capability 的类型、空、重复、未知选择，以及其余四个 profile 对该选择的显式拒绝。不把“schema可解析”当作这些 profile 支持新能力。

数据违约在空人口上按全称约束成立；坏声明在空人口上仍须预检拒绝，二者不能混用。

## 独立答案与证据

整数比较使用 BigInt，结果中的值与计数使用精确十进制字符串；不放宽旧公共 Cell 对不安全整数的拒绝。DATE 的独立日序计算不用 JS Date，并区分文本解析范围与底层物理存储范围。

单源与双源维度模型共用合同；双源保留重复FK、同名影子列和未引用维度。完整根/子对象、NULL/值分组、指标与独立手写SQL分别核对，COUNT不代替身份。每次加载前创建旧请求，失败时核对精确snapshot与成员；成功或失败后均核对旧prepared在重载及来源删除后的结果。

报告中的答案、预期错误、snapshot、prepared和来源删除必须对应逐次记录的实际SQL操作，不接受只有成功标记的报告。原始 `operations.jsonl` 按开始/完成事件记录；中断或不完整事件保持未知，不能作为通过。最终报告与原流重放必须完全一致。错误检查使用现有 error-v1 的 code、stage及适用约束对象/索引，不用任意数据库错误冒充预期拒绝。

## 入口、预算和限制

由 原生监督入口 在第一个阶段运行，随后保留原A/B、capture、31文件SQL与旧20阶段的完整断言。已验收的边界目录为 `.local-agent-evidence/concept-requires-boundaries-007`，当前已存在；
它是历史执行定位，不能作为下一次全新输出目录。新运行须审阅独立目录与绑定，不覆盖旧目录。

边界阶段外层150秒；内部10000次显式SQL、阶段间软检查120秒、原始操作流与最终报告各8MiB、无自动重试。内部计数不包含引擎内部绑定或校验查询；软检查不能打断一条正在运行的SQL。外层进程组所有权、输出限额、10秒清理和512MiB归档合同继续有效；整个run共享1500秒，包含阶段间绑定和等待。

输入使用固定schema及旧三文档模板，负控派生定义在独立目录写入新哈希，不改旧fixture。宿主完整源码/子模块/已安装依赖/工具/产物由监督层绑定；worker自身的文件pin不表示完整动态依赖或加载内存证明。失败保留日志、部分派生定义和原流；不修改查询来迎合输出。

本合同不覆盖新profile、一般Ontology推理、完整DATE/时间语法或任何时区政策、CLI/MCP、AMD64、公共发布或CI。需要改变语义或扩大支持范围时，先停下决策。
